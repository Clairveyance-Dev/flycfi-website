# flycfi.app

The public website for **FlyCFI** — home, support, privacy policy and terms.

This repository exists only to serve those four pages over HTTPS at
<https://flycfi.app> through GitHub Pages. It holds no application code
and no credentials.

The pages are authored in the FlyCFI project at
`01_Website/flycfi-website/` and copied here by
`scripts/deploy_website_pages.py`. **Edit them there, not here** — a
change made directly in this repository is overwritten by the next
deploy.
